# AZOTH security reporting

AZOTH — by Veilric is maintained under The Alchemical Order at [Veilric/AZOTH-pub-release](https://github.com/Veilric/AZOTH-pub-release). No private security-reporting channel or security support window is currently established.

Do not publish credentials, private documents, sensitive file paths, or exploit details that would expose users. Check whether its Security page offers private vulnerability reporting. If no private channel is offered, a public issue may request a contact method without including sensitive details. No email address or private reporting service is implied here.

For a non-sensitive report, include the operating system, application/engine version, minimal reproduction steps, and expected/observed behavior. Use disposable files and redact logs. Upstream Filee is a separate project; AZOTH-specific reports belong with AZOTH's maintainer.

Automatic update checks are disabled. Optional engine downloads retain their pinned sources and integrity checks; these checks do not establish that all inputs or third-party tools are safe. Local processing does not make untrusted documents harmless.

Antivirus detections reported during development remain unresolved and are not classified as false positives. Do not disable antivirus, add exclusions, or bypass an operating-system warning to run AZOTH. ECHO performs duplicate review, not malware detection, and native Windows Recycle Bin verification remains pending.
