# AZOTH changelog

## 0.1.1 — Initial Public Release

Initial public source and Windows/Linux package release of AZOTH — by Veilric, under The Alchemical Order.

- Integrate official AZOTH symbol and wordmark assets across application and installer branding.
- Present a sequential 1.4-second logo-only startup before the main interface; reduced motion skips it, tray reopening does not replay it, and minimizing completes the launch stage.
- Retain custom Donuts, compact action starters, optional advanced formats, and saved conversion recipes.
- Retain ECHO exact duplicate review and explicit Trash-based cleanup with candidate/survivor revalidation.
- Retain ORDO ordered rules, structured move previews, persistent operation history, verified undo, and opt-in monitoring for one source folder while AZOTH runs.
- Provide public source/build guidance and preserve upstream licensing and provenance. Automatic update checks remain disabled.

Native Windows installation/upgrade and Recycle Bin verification remain pending. Antivirus detections reported during development are unresolved. Downloaded Linux rhwp requires glibc 2.39; native Wayland and macOS behavior need further target-system verification. See [README.md](README.md) and [BUILDING.md](docs/BUILDING.md) for scope and limitations.

## 0.1.0 — Development baseline

- Introduce the independently branded AZOTH — by Veilric desktop application, based on Filee.
- Retain native desktop/CLI file-conversion workflows, presets, history, and watch folders.
- Separate AZOTH installation, settings, engine caches, IPC, and shell integration from Filee.
- Preserve upstream MIT licensing, copyright, dependency notices, and attribution.

Historical upstream releases are recorded in [docs/upstream/CHANGELOG.md](docs/upstream/CHANGELOG.md).
